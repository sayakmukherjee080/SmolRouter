[2026-11-07] [architecture] [all] Two price layers: upstream route costs in USD (auto-priced from the built-in map, admin override wins) and optional downstream prices on the model alias in the billing currency. Blank downstream prices mean pass-through; downstream prices may be set even for free upstream models. Admins see both; gateway keys see downstream only.
[2026-11-07] [architecture] [all] Budgets are unified per-token rules: metric (requests, tokens in/out/total, amount) x period (hour, n-hours, day, n-days, week, month), with timezone, reset time, and anchor. Exact synchronous reservations; existing daily/monthly caps migrate to rules; cache hits count as requests and consume cached tokens/amount. Amount rules use downstream charges.
[2026-11-07] [architecture] [all] LiteLLM compatibility is the API convention: `/v1/models` stays OpenAI-shaped; add `/model/info` and `/key/info` plus `x-litellm-*` spend/budget headers. Gateway keys see downstream prices and their own quota; admins see upstream and downstream.
[2026-11-07] [architecture] [all] Billing currency is configurable; upstream USD costs convert through a cached FX API (`FX_API_URL`, optional `FX_API_KEY`), and the rate is stored per usage row. Same-currency conversion is a passthrough; amount budgets fail closed when conversion is unavailable.
[2026-11-07] [architecture] [all] Analytics store requests, tokens in/out, upstream estimated and provider-reported cost, downstream billed, margin, and latency only. No prompt or completion content columns, logs, or APIs. The response cache remains in-memory and per-model opt-out.
[2026-11-07] [architecture] [all] Migration checksums are verified on boot (warn-only mismatch) — supersedes the "checksums deferred" note in the 2026-10-03 audit-fix defaults entry.
[2026-10-11] [infra] Tunnel mode: quick tunnel — tunnelled port 8787 for local testing.

[2026-11-07] [architecture] [all] Non-stream JSON responses are buffered for cost headers only up to `NONSTREAM_CAPTURE_MAX_BYTES` (default 262144); cache-eligible responses keep the response-cache body cap. Streaming responses never emit a final cost header.
[2026-11-07] [architecture] [all] Budget-rule windows longer than `TOKEN_USAGE_RETENTION_DAYS` are rejected; maintenance never prunes events inside an active budget window. In-flight reservations follow a replaced rule by its stable shape key instead of blocking admin edits.
[2026-11-07] [architecture] [all] LiteLLM compatibility intentionally omits `tpm_limit`, `rpm_limit`, `soft_budget`, and `max_parallel_requests`; `/model/info` reports `max_output_tokens: null` until an explicit output limit exists.
